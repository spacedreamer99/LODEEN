# Handoff — пауза до 2028

## Где остановился
Последний коммит перед freeze: `git log -1`.
Дата: 2026-10-07.

## Как запустить за 5 минут
    cd ~/Desktop/LODEEN
    sudo pkill -9 -f lodeen 2>/dev/null ; sleep 1 ; make dev

Откроются два клиента: pilot1, pilot2. В меню — выбрать ник, адрес (по умолчанию), цвет (16 на выбор), Connect.

## Что сделано
- **Server-authoritative** (ADR 0001): сервер симулирует всё, клиент рисует
- **Тонкий клиент** (ADR 0002): клиент шлёт input, читает snapshot
- **11 доменов на generic `store[T]`** — вместо 11 пар мьютексов
- **9 god-файлов разрезано** (172–824 строк каждый)
- **Все монолиты >62 строк устранены**
- **Player color picker**: 16 цветов в меню → уходит в Hello → сохраняется сервером → видно чужим игрокам
- **Nametags**: ник + цветовой маркер над головой, затухание 25→100м
- **Pre-commit**: build + vet + gofmt + `test -race`
- **CI**: race + coverage + gitleaks + hadolint + trivy + SARIF
- **Coverage**: `shared/protocol` 100%, `shared/version` 100%, `server/net` ~21%

## Что НЕ сделано (roadmap)
- Тесты `server/net` до 40–50% (чистые функции: `tickHostileMob`, `findNearestPlayer`, `collectBreedingCandidates`, `scatteredAround`)
- Интеграционный тест `Server ↔ Client` через `net.Pipe`
- Fuzz на `ReadFrame`
- Процедурный звук (см. заметки про audio-пакет)
- Абстракция ввода для `client/input/flight`

## Известные проблемы на момент freeze

### Геймплей
- **Много мелких багов** — точный список не задокументирован, найдено вручную при тестировании
- Начинать нужно с **прохождения базового цикла**: спавн → сбор → крафт → постройка → ракета → орбита
- Некоторые взаимодействия (крафт, контракты, мамонты) работают частично — нужна ревизия
- Звука нет совсем

### Инфраструктура (требует переработки)
- **CI/CD** — есть, но не проверен на реальной нагрузке. CI прогоняет build/vet/test/race, но не разворачивал ни разу
- **Helm-чарт** — написан, но не тестировался на живом k8s
- **Terraform** — есть для Yandex Cloud, не проверялся в проде
- **Ansible-роли** для k3s — написаны, не запускались
- **ArgoCD** — конфиг есть, ни разу не подключал
- **Prometheus rules** — есть burn-rate SLO, но не факт что сработают
- **Мониторинг** — не проверен в реальной эксплуатации
- **Docker образ** — собирается, но оптимизация (size, слои) не оптимизирована

### Документация (требует ревизии)
- **README** — быстро написанный, не выверен
- **docs/DEPLOY.md** — есть, но может не соответствовать актуальным манифестам
- **docs/FEDERATION.md**, **docs/LAUNCHER.md**, **docs/MODS.md** — концептуальные, не отражают реализацию
- **API протокола** — не документирован отдельно (см. `internal/shared/protocol/`)
- **Диаграммы архитектуры** — ASCII-наброски в `docs/adr/`, но нет нормальной схемы

### Код (технический долг)
- **Клиент** — много «магических чисел», разбросанных констант, дублирования
- **UI/UX** — на уровне «работает, но уродливо». Layout меню чинился три раза, всё ещё не оптимален
- **Рендер** — примитивные модели, нет анимаций кроме walk-phase
- **Звук** — отсутствует
- **Тесты `server/net`** — 21% покрытие, надо 40-50%
- **Интеграционные тесты** — нет
- **Fuzz на `ReadFrame`** — нет
- **Процедурная генерация звука** — наработки есть, не встроена

### Архитектурные вопросы (не решены)
- **Persistence** — сервер теряет мир при рестарте (нужна БД)
- **Аутентификация** — сейчас никакая (любой подключается с любым ником)
- **Federation** — описана в docs, не реализована
- **Anti-cheat** — работает «by construction» (клиент не симулирует), но нет rate-limiting, нет проверки частоты пакетов
- **Масштабирование** — один сервер = один мир, шардирования нет

### Оценка трудозатрат при возврате
- **1 неделя**: пройтись по базовому геймплею, починить критичные баги
- **2-3 недели**: довести тесты `server/net` до 40-50%, написать интеграционные
- **1-2 месяца**: вычистить клиент, добавить звук, отполировать UI
- **2-3 месяца**: persistence, аутентификация, мониторинг на живом сервере
- **6+ месяцев**: довести до состояния «можно показывать широкой публике»

**Проект в состоянии "работающий прототип", не "готовый продукт".**
