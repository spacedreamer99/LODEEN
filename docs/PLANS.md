# LODEEN — планы проекта

## Смысл

Полигон по кибербезопасности в формате мультиплеер-игры.
Open source, Apache 2.0. Не коммерция — обучение и портфолио.

## Движки

- Клиентский — 3D, LWJGL + OpenGL 3.3 Core
- Серверный — headless, свой DSL для скриптов

Оба движка — кодовые: работа через файл/скрипт на своём DSL.

## DSL

- Синтаксис: однострочность + КАПС
- Свой редактор с подсветкой синтаксиса
- Парсер: ANTLR4

## Графика

- PBR, SSO, shadow mapping (динамические тени, многоисточность)
- Низкое разрешение теней + сглаживание
- Лёгкая графика через Blender, без 3D-нейронок
